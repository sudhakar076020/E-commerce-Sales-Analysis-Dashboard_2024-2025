
# 🛒 E-commerce Sales Analysis Dashboard (2024-2025)

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data using Excel, MySQL, Python, and Power BI. The goal is to extract meaningful insights related to sales performance, customer behavior, and profitability.

---

## 🧰 Tools & Technologies

* Excel – Data Cleaning
* MySQL – Data Storage & Querying
* Python (Pandas, Matplotlib, Seaborn) – Data Analysis
* Power BI – Dashboard Visualization

---

## 🧹 Data Cleaning (Excel)

* Handled missing values using appropriate techniques (average/replace)
* Removed duplicate records
* Standardized text formats (UPPER, TRIM)
* Created calculated columns

---

## 🗄️ Database (MySQL)

* Created structured database and tables
* Imported cleaned dataset
* Performed queries:

  * Total Sales & Profit
  * Category-wise Sales
  * Top Customers
  * Monthly Trends

---

## 🐍 Data Analysis (Python)

* Used Pandas for data manipulation and aggregation
* Analyzed:

  * Sales by category and sub-category
  * Regional performance
  * Monthly sales trends
* Created visualizations using Matplotlib & Seaborn

---

## 📊 Power BI Dashboard Features

* KPIs:

  * Total Sales
  * Total Profit
  * Total Orders
  * Total Customers

* Visualizations:

  * Sales by Category
  * Sales by Sub-Category
  * Monthly Sales Trend
  * Sales by Region
  * Payment Mode Distribution (Donut Chart)

* Interactive Slicers:

  * Category
  * Region
  * Payment Mode

---

## 💡 Key Insights

* Certain categories contribute the highest revenue
* Some products generate losses despite high sales
* Regional sales distribution highlights top-performing areas
* Discounts impact profit margins significantly
* Customer payment preferences are dominated by specific modes

---

## 🎯 Conclusion

This project demonstrates an end-to-end data analysis workflow, from data cleaning to dashboard creation, helping in data-driven decision making.
